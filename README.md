# Be U

</center>


Be U is an online platform where users can explore and purchase a curated selection of minimal makeup and skincare products designed to enhance natural beauty.

Visit the live version of the Be U website today to explore our thoughtfully curated range of beauty products by clicking the link below 👇  
 
[be-u.vercel.app](https://be-u.vercel.app/)

## Technologies Used
The Be U website is built using the following technologies:

- React.js
- Tailwind CSS
- Typescript

## Features
The Be U website offers the following features:

- **Product Listings**: Browse through the available makeup and skincare products.

- **Filter Products**: Easily filter products based on various criteria such as category, rating, and product price to find exactly what you need.

- **Responsive Design**: Enjoy a seamless experience on different devices.

- **Shopping Cart and Checkout**: Provides users with the ability to seamlessly add items, adjust quantities, and proceed through a streamlined checkout process.

## Getting Started

### Prerequisites

- **Node.js**: Make sure you have Node.js installed. You can download it from [https://nodejs.org/](https://nodejs.org/).

### Installation

1. **Clone this repository:**

    ```bash
    git clone https://github.com/pritha004/be-you.git
    ```

2. **Install dependencies:**

    ```bash
    cd frontend
    npm install
    ```

3. **Create a `.env` file in the `frontend` folder and set the following environment variables:**

    ```env
    VITE_STRIPE_SECRET_KEY= your_stripe_secret_key
    VITE_STRIPE_PUBLISHABLE_KEY= your_stripe_public_key
    VITE_CLIENT_URL= your_client_url
    ```

4. **Start the application (from the `frontend` folder):**

    ```bash
    npm run dev
    ```

5. **Search for `TODO` in the application and make necessary changes.**
